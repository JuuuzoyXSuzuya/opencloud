# Плагины OpenCloud (.oc)

Плагин OpenCloud — это **зашифрованный JSON-пресет**, а не исполняемый код.
Файл `.oc` нельзя прочитать или изменить обычным редактором: приложение
расшифровывает его встроенным ключом и применяет только известные ему действия.

## Что умеет плагин

Плагин не запускает произвольный код (это защищает и от вредоносных файлов, и
от несовместимости с будущими версиями TikTok). Он может:

| Действие | JSON | Что делает |
|---|---|---|
| Тёмная тема | `{"type":"dark_theme","enabled":true}` | принудительно включает тёмную тему (`false` — системную) и сразу применяет её |
| Регион | `{"type":"region","country":"us","operator":"310260"}` | выбирает страну и оператора из `data/countries.tsv` |
| Встроенный плагин | `{"type":"plugin","id":"dark_theme","enabled":false}` | переключает любой runtime-плагин по id |

`country` — ISO-код из таблицы, `operator` — MCC+MNC. Если оператор не указан,
берётся первый оператор страны.

## Формат файла

```
"OCP1" | nonce (12 байт) | AES-256-GCM(ciphertext) + tag (16 байт)
```

- Ключ: 32 байта, хранится в коде не в открытом виде, а как XOR-маска поверх
  SHA-256. Тот же ключ использует сборщик `tools/ocplugin.sh`.
- Шифрование: AES-256-GCM, случайный nonce на каждый файл, тег проверяется при
  импорте — подделанный или обрезанный файл не откроется.
- Внутри — обычный UTF-8 JSON.

### Ограничение безопасности

Ключ находится на стороне клиента (в APK и в сборщике). Он не лежит открытым
текстом, но настойчивый реверс-инженер теоретически может его извлечь. Это
защита от «просто открыть файл и поменять настройки», а не криптостойкая DRM.

## Схема JSON

```json
{
  "id": "dark-us-tmobile",
  "name": "Dark US — T-Mobile",
  "version": 1,
  "author": "OpenCloud",
  "description": "Тёмная тема и регион США.",
  "actions": [
    { "type": "dark_theme", "enabled": true },
    { "type": "region", "country": "us", "operator": "310260" }
  ]
}
```

- `id` — `[a-zA-Z0-9._-]`, до 48 символов, должен быть уникальным;
- `name` — обязателен;
- `version` — целое, по умолчанию 1;
- `actions` — массив действий, порядок сохраняется;
- размер файла — не больше 1 МБ.

## Сборка .oc

```bash
./tools/ocplugin.sh pack examples/dark-us-tmobile.json examples/dark-us-tmobile.oc
```

Проверить содержимое (для отладки):

```bash
./tools/ocplugin.sh unpack examples/dark-us-tmobile.oc /tmp/plugin.json
```

Для сборщика нужен JDK 17+; скрипт ищет `JAVA`, затем `~/opt/jdk-21.0.13+9`,
затем `java` из `PATH`.

## Импорт в приложении

1. Откройте **Настройки OpenCloud** (строка в настройках TikTok или иконка
   OpenCloud).
2. В разделе **Кастомные плагины** нажмите **Импортировать .oc**.
3. Выберите один или несколько файлов (поддерживается мультивыбор). Они
   расшифруются и появятся в списке.
4. **Применить** — выполняет действия пресета; **Удалить** — убирает его.

## Экспорт из приложения

Кнопка **Экспортировать настройки в .oc** сохраняет текущий регион и режим
темы в новый зашифрованный файл. Его можно передать другому устройству и
импортировать там.

Расшифрованный JSON хранится в приватном каталоге приложения
(`files/opencloud/plugins/<id>.json`), поэтому другие приложения его не видят.

## Готовые примеры

- `examples/dark-us-tmobile.oc`
- `examples/dark-de-telekom.oc`

Исходные JSON лежат рядом; их можно менять и пересобирать командой выше.
