# Шрифты

OpenCloud умеет подменять шрифт двумя способами:

- **системный** — по умолчанию приложение использует обычный шрифт Android;
- **выбранный** — один из шрифтов, установленных в системе (`/system/fonts`),
  либо свой файл `.ttf` / `.otf`.

## Где выбрать

В экране **Настройки OpenCloud** есть раздел **«Шрифт»**:

1. Нажмите **«Выбрать шрифт»**.
2. Выберите **«Системный (по умолчанию)»**, один из системных шрифтов или
   нажмите **«Загрузить .ttf / .otf»** и укажите файл.
3. Переключатель **«Применять шрифт в TikTok»** решает, менять ли шрифт самого
   TikTok (по умолчанию включается при выборе шрифта).

Экран OpenCloud применяет выбранный шрифт сразу. TikTok подхватывает его после
перезапуска: шрифты читаются при создании текстовых элементов.

## Системные шрифты

Список строится сканированием `/system/fonts`. Цветные emoji-шрифты
(`*emoji*`, `*color*`) в список не попадают — они не годятся как основной
шрифт интерфейса.

## Свой файл

Импортированный файл копируется в приватный каталог приложения
`files/fonts/` и проверяется через `Typeface.createFromFile`. Если файл не
является шрифтом, импорт отменяется, а старая копия удаляется. Кнопка
**«Сбросить на системный шрифт»** в том же диалоге удаляет выбор, а общий
**«Сбросить настройки OpenCloud»** — ещё и сам файл.

## Как это работает

Патчер переписывает вызовы `Typeface` в dex-файлах TikTok на мост
`Hooks`:

| Оригинал | Мост |
|---|---|
| `Typeface.create(String, int)` | `Hooks.typeface(String, int)` |
| `Typeface.create(Typeface, int)` | `Hooks.typeface(Typeface, int)` |
| `Typeface.defaultFromStyle(int)` | `Hooks.defaultTypeface(int)` |
| `Typeface.createFromAsset(AssetManager, String)` | `Hooks.typefaceFromAsset(...)` |
| `Typeface.createFromFile(String)` | `Hooks.typefaceFromFile(String)` |

Мост возвращает выбранный шрифт только если он задан и включён плагин
`custom_font`; иначе вызывается исходный метод Android. Толщина и курсив
сохраняются: для жирного текста шрифт синтезируется через
`Typeface.create(base, style)`, а в именах файлов вроде `Bold` / `Italic`
стиль определяется автоматически.

Специально **не** подменяются:

- LaTeX-шрифты `jlm_*` (формулы);
- `*combo_font*` (счётчики подарков в прямых эфирах);
- emoji- и иконочные шрифты (`*emoji*`, `*icon*`).

Так иконки и формулы остаются читаемыми, даже если выбранный шрифт их не
содержит.

## Ограничения

- Часть текста TikTok рисует шрифтами, зашитыми в ресурсы и загружаемыми в
  обход перечисленных вызовов; такие надписи могут остаться прежними.
- Если выбранный файл удалить или переименовать, мост вернётся к системному
  шрифту без падения приложения.
- Шрифт не входит в экспорт `.oc`: файл шрифта — это отдельный бинарный
  ресурс, его нужно переносить отдельно.
